# 零界行动 II

BUILD 03.00。一个使用 WebGL 和 Web Audio 的第一人称射击小游戏，包含 AK、M9 风格刀具、三波敌人、爆头奖励与可练习的连射压枪。

## 地图

在开始菜单选择地图，再点击开始游戏。

| 地图 | 场景 |
| --- | --- |
| 训练场 | 原有训练地图，适合熟悉移动和压枪。 |
| 工业港湾货场 | 仓库、冷却烟囱与海运集装箱组成的工业场景。 |
| 遗迹回廊 | 城墙、雉堞塔与岩石掩体组成的遗迹场景。 |
| 星港前哨 | 科幻终端、支柱与货物容器组成的太空基地。 |

后三张地图使用 Kenney 的 CC0 模型重新设计布局、掩体和游戏配置；它们是本项目制作的关卡，不是下载得到的现成完整地图。素材来源见 [第三方说明](THIRD_PARTY_NOTICES.md)。

## 本地运行

安装 Node.js 后，在项目目录运行：

```sh
node serve.cjs
```

也可以运行：

```sh
npm start
```

然后打开 [http://localhost:4173/](http://localhost:4173/)。停止服务时，在终端按 `Ctrl+C`。游戏页面不需要登录。

## 操作

| 输入 | 操作 |
| --- | --- |
| W / A / S / D | 移动 |
| 鼠标 | 转动视角 |
| 鼠标左键 | AK 射击 / 刀具挥砍 |
| Shift | 按住蹲下 |
| 空格 | 跳跃 |
| R | AK 换弹 |
| 1 / 3 | 切换 AK / 刀具 |
| Q | 切换武器 |
| Esc | 释放鼠标并暂停 |

AK 弹匣容量为 30 发，连射间隔为 100 毫秒。移动会增加弹道扩散，速度降低后恢复精度；连续开火会按参考轨迹累积弹道偏移，需要用鼠标反向补偿。枪身随轨迹抬起、落下，停火后平滑复位。准星保持固定，弹道偏移由射线和可见轨迹呈现。

手机使用左下摇杆移动、滑动转向、左上射击键开火及右侧操作键。手机页面从开始菜单到游戏界面采用横屏布局，竖持设备时页面会旋转显示；布局不依赖浏览器是否支持系统横屏锁定。

## 文件与离线运行

- `index.html`：开始菜单、HUD 和操作控件。
- `style.css`：界面样式与手机横屏布局。
- `game.js`：渲染、游戏逻辑、内嵌模型和音效数据。
- `serve.cjs`：本地静态文件服务。

模型和音效随页面提供，运行时无需下载外部模型、音频或调用在线游戏接口。在本地启动服务后，没有公网连接也可以游玩。高分和设置保存在当前浏览器的本地存储中。
