# 零界行动 II

BUILD 03.11。一个使用 WebGL 和 Web Audio 的第一人称射击小游戏，包含 AK、M9 风格刀具、三波奶蛙、刀盾狗与女巫、爆头奖励及可练习的连射压枪。

## 地图

在开始菜单选择地图，再点击开始游戏。

| 地图 | 场景 |
| --- | --- |
| 训练场 | 分区路面、战术标线、编号掩体与管线，适合熟悉移动和压枪。 |
| 工业港湾货场 | 仓库、烟囱、集装箱与装卸场标线、排水和港口结构细节。 |
| 遗迹回廊 | 石材铺装、断墙砖缝、城塔、墙根碎石与植被。 |
| 星港前哨 | 金属地板、发光导向、终端面板与分层反应堆结构。 |

后三张地图使用 Kenney 的 CC0 模型重新设计布局、掩体和游戏配置；它们是本项目制作的关卡，不是下载得到的现成完整地图。素材来源见 [第三方说明](THIRD_PARTY_NOTICES.md)。

地图装饰按关卡一次生成并缓存，切换回来时复用；路线、掩体碰撞、出生点和补给点保持原布局。

## 本地运行

安装 Node.js 后，在项目目录运行：

```sh
node serve.cjs
```

也可以运行：

```sh
npm start
```

然后打开 [http://localhost:4173/](http://localhost:4173/)。停止服务时，在终端按 `Ctrl+C`。游戏页面不需要登录。

## 操作

| 输入 | 操作 |
| --- | --- |
| W / A / S / D | 移动 |
| 鼠标 | 转动视角 |
| 鼠标左键 | AK 射击 / 刀具挥砍 |
| Shift | 按住蹲下 |
| 空格 / 鼠标滚轮向下 | 跳跃 |

| Q | 切换武器 |
| Esc | 释放鼠标并暂停 |

AK 弹匣容量为 30 发，连射间隔为 100 毫秒。连续按住开火会按参考轨迹累积弹道偏移，需要用鼠标反向补偿。松开鼠标左键、F 键或触屏射击键时，立即重置连射顺序与弹道偏移，下一轮从首发开始；手动瞄准方向与剩余射击冷却保持不变。枪身随轨迹抬起、落下，松开后继续平滑复位。准星保持固定，弹道偏移由射线和可见轨迹呈现。

第一人称显示战术手套、手指、袖口和前臂：AK 右手握持握把，左手托住护木；M9 由右手握柄。双手与武器共享开火、压枪、装填、切换和挥刀变换，不改变瞄准或弹道。

地面水平速度低于 3.0 时精准，蹲走速度 2.86 因而保持精准；普通移动速度为 6.24。等于或高于阈值时，移动散布随速度由 0.7° 增至 5.88°，比之前增加 40%；空中散布至少为 5.5°。松开移动键会滑行减速，按反方向可更快急停。

手机使用左下摇杆移动、滑动转向、左上射击键开火及右侧操作键。手机页面从开始菜单到游戏界面采用横屏布局，竖持设备时页面会旋转显示；布局不依赖浏览器是否支持系统横屏锁定。

## 敌人

奶蛙通过远程光球攻击，刀盾狗佩戴像素剑和盾牌，并用前爪进行近战攻击。紫袍尖帽女巫负责治疗与攻速支援，每波出现 1 个，替换一个奶蛙，三波总数保持 4 / 6 / 8。

敌人会绕过集装箱、长墙和拐角，并在玩家换位后更新路线；奶蛙隔着掩体时会继续寻找能射击的位置。三类敌人分别按体型留出通行空间，并会避让同伴。

- 刀盾狗的移动速度为奶蛙的 3.3 倍，生命值为新兵 18、标准和精英 24。攻击速度翻倍：举爪前摇 0.16 秒、挥击 0.08 秒、收爪 0.24 秒，收爪后间隔 0.275 秒再攻击；单次伤害保持新兵 12、标准 18、精英 26。攻击范围扩大 20%，触发距离 2.22，命中距离 2.34；可在前摇时横移或拉开距离躲避。
- 被刀盾狗爪击后会流血 3 秒，每秒损失 3 点生命；重复爪击只刷新持续时间，不叠加伤害，也不重置每秒扣血计时。暂停时流血计时冻结，死亡或重新开始会清除流血。
- 击退刀盾狗必定掉落补给：恢复 40 点生命（上限 100）及补充 45 发备弹；基础得分为 `200 + 当前波数 × 40`。
- 奶蛙攻速提高 50%，完整发射周期缩短三分之一，首次发球也更快；保留 0.24 秒蓄力和 0.20 秒收招动画。光球速度为每秒 35，相比原来的 14 增加 150%；伤害仍为新兵 6、标准 9、精英 14。
- 命中头部造成 4 倍伤害，爆头击杀额外获得 50 分。
- 女巫移动速度为奶蛙的 65%，生命值为新兵 6、标准 8、精英 10。7 米内、无遮挡的其他存活敌人受到支援：每 2 秒恢复 1 点生命，最多恢复到初始血量；奶蛙与刀盾狗攻速提高 20%，移动速度、弹速和单次伤害不变。多名女巫的效果不叠加，女巫不治疗自己、不直接攻击玩家。
- 绿色范围环标示女巫支援半径，受支援单位脚下有紫色光环，治疗时浮现绿色十字。离开范围、被障碍遮挡或女巫死亡后，攻速支援立即解除。优先击退女巫可减轻战斗压力；女巫基础得分为 `150 + 当前波数 × 30`。

## 文件与离线运行

- `index.html`：开始菜单、HUD 和操作控件。
- `style.css`：界面样式与手机横屏布局。
- `game.js`：渲染、游戏逻辑、内嵌模型和音效数据。
- `serve.cjs`：本地静态文件服务。

AK 音效从提供的游戏录像提取，音量降低约 15%，保留起音，尾音逐渐衰减。每次命中头部保留短促击中声；爆头击杀时，再立即播放最早提供的独立 WAV。击杀音效移除了前导约 86.5 毫秒的等待段，保留主体、尾音、立体声及原音高，非致死命中不会触发。三种音效均内嵌缓存。模型和音效随页面提供，运行时无需下载外部模型、音频或调用在线游戏接口。在本地启动服务后，没有公网连接也可以游玩。高分和设置保存在当前浏览器的本地存储中。
