# 零界行动 II

BUILD 03.12。一个使用 WebGL 和 Web Audio 的第一人称射击小游戏：使用 AK 或 M9 风格刀具抵御奶蛙、刀盾狗与女巫组成的无尽尸潮，挑战存活时间，练习连射压枪，并争取爆头奖励。

## 地图

在开始菜单选择地图，再点击开始游戏。

| 地图 | 场景 |
| --- | --- |
| 训练场 | 分区路面、战术标线、编号掩体与管线，适合熟悉移动和压枪。 |
| 工业港湾货场 | 仓库、烟囱、集装箱与装卸场标线、排水和港口结构细节。 |
| 遗迹回廊 | 石材铺装、断墙砖缝、城塔、墙根碎石与植被。 |
| 星港前哨 | 金属地板、发光导向、终端面板与分层反应堆结构。 |

后三张地图使用 Kenney 的 CC0 模型重新设计布局、掩体和游戏配置；它们是本项目制作的地图，不是下载得到的现成完整地图。素材来源见 [第三方说明](THIRD_PARTY_NOTICES.md)。

地图装饰按地图一次生成并缓存，切换回来时复用；路线、掩体碰撞、出生点和补给点保持原布局。

## 本地运行

安装 Node.js 后，在项目目录运行：

```sh
node serve.cjs
```

也可以运行：

```sh
npm start
```

然后打开 [http://localhost:4173/](http://localhost:4173/)。停止服务时，在终端按 `Ctrl+C`。游戏页面不需要登录。

## 操作

| 输入 | 操作 |
| --- | --- |
| W / A / S / D | 移动 |
| 鼠标 | 转动视角 |
| 鼠标左键 | AK 射击 / 刀具挥砍 |
| Shift | 按住蹲下 |
| 空格 / 鼠标滚轮向下 | 跳跃 |
| R | AK 换弹 |
| 1 / 3 | 切换 AK / 刀具 |
| Q | 施放全场冰冻 |
| Esc | 释放鼠标并暂停 |

AK 弹匣容量为 30 发，连射间隔为 100 毫秒。连续按住开火会按参考轨迹累积弹道偏移，需要用鼠标反向补偿。松开鼠标左键、F 键或触屏射击键时，立即重置连射顺序与弹道偏移，下一轮从首发开始；手动瞄准方向与剩余射击冷却保持不变。枪身随轨迹抬起、落下，松开后继续平滑复位。准星保持固定，弹道偏移由射线和可见轨迹呈现。

第一人称显示战术手套、手指、袖口和前臂：AK 右手握持握把，左手托住护木；M9 由右手握柄。双手与武器共享开火、压枪、装填、切换和挥刀变换，不改变瞄准或弹道。

地面水平速度低于 3.6 时精准，蹲走速度 3.432 因而保持精准；普通移动速度为 7.488，比上一版再提高 20%，加速与急停减速同步调整以保持操作节奏。等于或高于阈值时，移动散布随速度由 0.7° 增至 5.88°，比之前增加 40%；空中散布至少为 5.5°。松开移动键会滑行减速，按反方向可更快急停。

手机使用左下摇杆移动、滑动转向、左上射击键开火及右侧操作键；右侧雪花按钮施放全场冰冻。左上射击键放大 50%，瞄准图标半透明；左下摇杆放大 20% 并向右移动 16 像素，血条保持与摇杆叠放。手机页面从开始菜单到游戏界面采用横屏布局，竖持设备时页面会旋转显示；布局不依赖浏览器是否支持系统横屏锁定。

每局初始即可使用全场冰冻：按 Q 或轻触雪花按钮施放，冷却 25 秒。基础效果将全场敌人冻结 3 秒，解冻后移动速度降低 50%，持续 2 秒。技能状态显示就绪、冻结或冷却时间，冻结时屏幕边缘出现淡淡冰霜。Q 不再切回上一把武器；切换武器使用 1 / 3 或手机切换按钮。

## 无尽尸潮

开局随机出现 4 只敌人，随后持续逐只刷出，没有关卡切换或自动通关。奶蛙、刀盾狗、女巫按 `40 : 30 : 40` 的权重随机选择，实际概率约为 36.4%、27.3%、36.4%。

刷怪间隔随存活时间缩短：`max(0.5, 2.8 × 0.86^(存活秒数 / 30))` 秒，从 2.8 秒逐步降至最低 0.5 秒。同屏敌人上限随等级增加：Lv 1～9 为 20 只，Lv 10～19 为 22 只，Lv 20～29 为 24 只，之后每 10 级增加 2 只（Boss 也计入上限），没有新的固定上限。满员时暂缓刷新，不积压等待之后补刷。

自然刷新的敌人与玩家至少保持 12 米距离，优先出现在玩家视野外或被掩体遮挡的位置。

界面显示存活时间与场上敌人数。不会通过清空场上敌人触发过关、回血或自动换弹；生命值降到 0 才结算本轮的存活时间、得分与击退数量。暂停会冻结游戏计时。

## 经验与升级

每局从 Lv 1、0 / 100 经验开始，击退奶蛙获得 10 经验、刀盾狗 20 经验、女巫 25 经验、火龙 Boss 100 经验。升级所需经验每 5 级增加 30：当前 Lv 1～5 时，下一次升级需要 100 经验；Lv 6～10 时需要 130，Lv 11～15 时需要 160，Lv 16～20 时需要 190，以此类推。达到 Lv 2、4、6、8……时才给予升级奖励，奇数级仅提升等级；每 10 级的大升级照常并替代当次普通奖励。选择奖励时战斗暂停，可点击卡片选择一项强化；普通升级支持数字 1～3，大升级按显示的卡片编号选择；手机横屏下可直接轻触卡片。HUD 显示当前等级、经验进度与生命上限，结算显示本局等级。所有经验和强化在新一局重置。

普通升级从以下五项随机提供三项，已达到上限的选项退出候选池：

| 普通强化 | 每次选择的效果 |
| --- | --- |
| 子弹基础伤害 | AK 子弹基础伤害 +1；初始身体伤害为 1，第一次选择后为 2，爆头仍乘 4。 |
| 换弹速度 | 换弹速度 +20%，最多选择 10 次，累计 +200%；满级时装填时长为初始的三分之一。达到上限后，该选项退出候选池，继续从未满级的其余选项中随机显示三项。 |
| 生命强化 | 最大生命 +20，同时恢复 20 点当前生命，不超过新的上限。 |
| 通用伤害 | 伤害加成 +20%，适用于 AK 和刀具；多次选择按百分比相加。 |

| 闪避 | 闪避概率每次 +5%，默认上限 40%；获得闪避衣后上限 70%。直接攻击闪避成功时不受伤，也不触发爪击流血；已经存在的流血持续结算。 |

达到 Lv 10、20、30……时，大升级替代当次普通升级，完整展示五项基础大强化，获得火焰护盾后增加第六项护盾强化，每次任选一项。桌面可点击或按卡片编号，手机可上下滑动查看全部技能后轻触选择：

| 大强化 | 每次选择的效果 |
| --- | --- |
| 命中吸血 | 按 AK 子弹实际造成伤害的 30% 恢复生命；每次再选增加 30 个百分点，即 30%、60%、90%……。爆头按实际伤害计算，超过敌人剩余生命的过量伤害不计，恢复不超过自身生命上限。刀具与未命中的子弹不会触发。 |
| 强效伤害 | 通用伤害加成 +30%，与普通伤害加成相加，适用于 AK 和刀具。 |
| 强效生命 | 最大生命 +50，同时恢复 50 点当前生命，不超过新的上限。 |
| 冰冻强化 | 每次选择使冻结时间 +1 秒、解冻后的减速时间 +2 秒，可无限重复选择；减速幅度仍为 50%，技能冷却仍为 25 秒。 |
| 子弹伤害 +3 | AK 子弹基础伤害 +3，可无限重复选择，并继续受到通用伤害加成与爆头倍率影响。 |
| 护盾强化（获得护盾后出现） | 护盾上限 +30，同时补充 30 点当前护盾，可重复选择。 |

每到 20、40、60……级，会触发下一只大火龙奶娃 Boss，前一只存活时等待其被击败；满员时等待空位出现。Boss 是奶蛙的 1.6 倍体型，带有橙红鳞甲、犄角和龙翼，首只基础生命为 2000，后续每只增加 150%（乘 2.5），依次为 2000、5000、12500……，并受敌人成长加成影响。三发火球前有 0.9 秒蓄力，近距离扇形喷火前有 1.1 秒预警；观察橙色火球与地面扇形边界，及时移动或利用掩体躲避。出现 Boss 时，HUD 显示其生命条。

击败 Boss 会留下永久宝箱，靠近后暂停战斗，任选一个尚未拥有的奖励：

- **火焰子弹**：仅从宝箱解锁，不再属于大升级。AK 命中后点燃原目标 3 米内最多 2 个其他敌人，每个灼烧持续 3 秒，在第 1、2、3 秒各受到该发子弹计算伤害的 10%，合计 30%；不会重复计算通用伤害加成，也不会递归连锁。
- **火焰护盾**：解锁 50 点护盾，优先抵挡伤害。每次受伤后，从剩余护盾开始，在 5 秒内线性补满；再次受伤会重新开始这段恢复过程。获得护盾后，大升级会额外展示护盾强化。护盾小条位于生命条上方，吸收伤害时屏幕边缘短暂出现橙色反馈。

宝箱没有普通掉落物的 5 秒消失期限，选择奖励后恢复战斗；奖励与护盾在新一局重置。六项装备均已获得后，后续 Boss 不再掉落技能宝箱。再次点燃刷新 3 秒持续时间，使用更强的单次灼烧伤害，不叠加多层灼烧；灼烧不触发额外吸血。

敌人也会随击退数量变强：每累计击退 20 只，敌方生命增加基础值的 15%，伤害增加基础值的 7%，均按百分比相加；累计 40 只时生命 +30%、伤害 +14%，60 只时生命 +45%、伤害 +21%。存活敌人保留原来的生命百分比，已发射的攻击保留发射时的伤害倍率。


宝箱每次仍只能选一项，新增四件唯一装备：

- 闪避衣：把闪避上限提高到 70%，不直接增加当前概率，继续通过普通闪避奖励每次 +5%。
- 免伤之衣：单次重击限制为自身最大生命的 20%，触发冷却 3 秒；只有超出该限制的攻击消耗冷却。闪避先判定，然后免伤，再由护盾抵挡剩余伤害。
- 名刀司命：本局免除一次致命伤害，立即恢复到最大生命的 50%；使用后失效，新一局清除。
- 血量转换器：从获得时开始统计，每击败 5 个敌人，增加本局生命上限 1 点并恢复 1 点生命，无上限。

敌人保持约 0.4 米额外间隙，拥挤时逐渐分散；贴墙和窄道处优先遵守障碍物碰撞。HUD 显示闪避概率、免伤衣冷却、名刀是否已使用和转换器进度。

## 敌人

三类敌人均为立体模型。奶蛙发射远程光球，刀盾狗佩戴像素剑和盾牌并用前爪近战，紫袍尖帽女巫提供复活与攻速支援，并投掷伤害药水。敌人会绕过集装箱、长墙和拐角，按体型留出通行空间并避让同伴；玩家换位后会更新路线，奶蛙隔着掩体时会继续寻找能射击的位置。以下生命与直接攻击伤害为初始数值，随累计击退数量获得上述成长加成。

- 奶蛙每轮连续发射 3 颗光球，球间隔 0.12 秒，完整攻击轮次仍使用此前提高 50% 后的频率；保留 0.24 秒蓄力和 0.20 秒收招。每颗光球速度为每秒 35，单发伤害为新兵 6、标准 9、精英 14。可通过掩体或移动躲避。
- 刀盾狗速度为奶蛙的 3.3 倍，生命值为新兵 18、标准和精英 24。举爪前摇 0.16 秒、挥击 0.08 秒、收爪 0.24 秒，收爪后间隔 0.275 秒再攻击；单次伤害为新兵 12、标准 18、精英 26。触发距离 2.22 米，命中距离 2.34 米，可在前摇时横移或拉开距离躲避。
- 被刀盾狗爪击后会流血 3 秒，每秒损失 3 点生命；重复爪击只刷新持续时间，不叠加伤害，也不重置每秒扣血计时。暂停时流血计时冻结，死亡或重新开始会清除流血。击退刀盾狗必定掉落补给，拾取恢复 40 点生命（不超过当前生命上限）及补充 45 发备弹。
- 击杀掉落的补给会在 5 秒内逐渐缩小并消失，需及时拾取；暂停或升级选择时倒计时停止，过期补给不再提供生命和弹药。地图预放的补给不受此期限影响。
- 女巫与奶蛙同速，优先绕过障碍物接近最近的存活伤员，进入支援范围，伤员也可以是另一名女巫；没有受伤队友时则主动接近玩家。生命值为新兵 6、标准 8、精英 10。她为 7 米内、无遮挡的奶蛙与刀盾狗提供 20% 攻速加成，不改变移动速度、弹速或单次伤害。多名女巫的光环不叠加，离开范围、被障碍遮挡或女巫死亡后解除支援。
- 女巫的绿色支援改为复活：死亡不超过 5 秒的敌人进入存活女巫 7 米范围内时，可获得一次 30% 概率的复活判定。成功后以最大生命的 50% 返回战场。每个敌人只判定一次，失败不会因另一名女巫重复尝试，复活后再次死亡也不能重试；不再投掷治疗药瓶或直接为存活队友回血。
- 紫色伤害药水投掷距离为 16 米，完整攻击周期约 3.6 秒。落点半径 3 米内、未被实墙阻隔的玩家受到一次基础 30 点伤害，三个难度相同；敌方队友不会受伤。投掷有抬手前摇，飞行药瓶、落点圈、药雾与碎片都以紫色区分。
- 女巫脚下的绿色边界环表示支援半径，受支援单位脚下显示光环。复活成功时出现青绿色上升符文、碎光与细光柱，约 1.2 秒后收束消散，与紫色伤害喷溅区分。优先击退女巫可减轻战斗压力。
- 命中头部造成 4 倍伤害，爆头击杀额外获得 50 分。

## 文件与离线运行

- `index.html`：开始菜单、HUD 和操作控件。
- `style.css`：界面样式与手机横屏布局。
- `game.js`：渲染、游戏逻辑、内嵌模型和音效数据。
- `serve.cjs`：本地静态文件服务。

AK 音效从提供的游戏录像提取，音量降低约 15%，保留起音，尾音逐渐衰减。每次命中头部保留短促击中声；爆头击杀时，再立即播放最早提供的独立 WAV。击杀音效移除了前导约 86.5 毫秒的等待段，保留主体、尾音、立体声及原音高，非致死命中不会触发。三种音效均内嵌缓存。模型和音效随页面提供，运行时无需下载外部模型、音频或调用在线游戏接口。在本地启动服务后，没有公网连接也可以游玩。高分和设置保存在当前浏览器的本地存储中。
